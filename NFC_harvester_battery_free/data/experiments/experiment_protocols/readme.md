# Experiment protocols
Protocols used to determine which steps to undertake while performing experiments with the densor. A description per protocol can be found below
## all_examples_v1.json
Combination of all possible tasks. Made to be excluded from machine learning models.
## all_examples_v2.json
Combination of all possible tasks including head rotation while laying. Made to be excluded from machine learning models.
## ear_mouth_v1.json
Only opening and closing the mouth repeaditly. Made to be seperable from other experiments containing mouth open and close events.
## grinding_v1.json
Repeaditly grind and not grind teeth.
## not_wearing_v1.json
Created to collect data where the Densor in not worn. Used for orthodontic compliance classification.
## open_close_speak_drink_v1.json
Main protocol used for most experiments. Wear with mouth opened and closed, speaking and drinking events.
## rotation_v1.json
Used to verify rotation readings and calculation from the accelerometer. Made to be excluded from machine learning models.
## sleeping_v1.json
Used to detect head rotation while sleeping.
