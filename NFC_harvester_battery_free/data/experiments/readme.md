# Data - Experiments
All scripts and data used for the machine learning experiments.

## Folders

### data_dumps
Folder containing the raw data obtained from the densor for this experiment.

### experiment_protocols
Folder containing the protocols used during the experiments. Can be loaded in experiment_master_ui.py.

### labeled_data
Folder containing CSV files with labeled data from the Densor

### labeled_data_ear_mouth
Folder containing CSV files with labeled data from the ear-mounted accelerometer.

### plots
Folder where plots generated by scripts in the data/experiments folder are stored.

## Files

### data_labeler.py
File containing methods to label data generated by the Densor and the ear-mounted accelerometer. Uses the index.json file to find the corresponding protocol.

### data_master.py
Script used to label Densor and ear-mounted accelerometer data.

### data_ml.py
Program that handles all machine learning on Densor data.

### data_process_apple_watch_dumps.py
Script to convert an Apple healthkit export into a protocol that can be used to label Densor data.

### data_stats.py
Script that holds methods for plotting machine learning related plots.

### earpiece_ml.py
Program that handles all machine learning on ear-mounted accelerometer data.

### experiment_master_ui.py
User interface for a program used to run experiments. Randomizes tasks, displays them to the user, gives a timer for every task and saves protocols to the index file after running.

### experiment_master.py
Background methods and command-line version of program controlling the experiments. Randomizes tasks, displays them to the user, gives a timer for every task and saves protocols to the index file after running.

### index.json
JSON file containing all data (including the protocol used) for every dataset in the data_dumps and labeled_data folder.

### plot_labeled.py
Program to plot labeled Densor data.

### plot_ear_mouth_example_trace.py
Program to plot an example trace of all sensors used in the comparison between ear and mouth experiment. Different traces can be generated by using the arguments "--mimu" for the Densor accelerometer trace, "-mpd" for the Densor photo-diode trace and "--ear" for the ear-mounted accelerometer trace.
