# Data Dumps
All collected data from the retainers. This readme contains the meta data of the data dumps. </br>
Naming convention for the files: `yy-mm-dd-<test_subject>-<label>-<index>.bin`
- yy-mm-dd: date
- test_subject: p, followed by subject number. Subject number is 0 if no-one was wearing it.
  - label:
  - c: controlled test
  - s: sleeping
  - a: awake
  - i: intake
- index: index of the binary file, index per day, per user
